## **Get Comprehensive Search Status**

Returns the status and results of a [Comprehensive Search](/enterprise-api/trace/comprehensive-search) job. Polling is **free**.

*   <Method type="GET">GET</Method> `/trace/v3/comprehensive1/jobs/{job_id}`

This endpoint returns exactly the same response as [`GET /trace/v3/jobs/{job_id}`](/enterprise-api/trace/search-status). Use whichever you prefer.

### **Path Parameters**

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `job_id` | string | ✅ | The `job_id` returned by `POST /trace/v3/comprehensive1` |

```bash cURL
curl "https://apiv2.soundverse.ai/trace/v3/comprehensive1/jobs/0190a1c0-3333-7000-8000-000000000103" \
  -H "Authorization: Bearer sksoundverse_your_api_key"
```

### **Response**

**Status 200 OK** (completed, `1:n`)
```json
{
  "success": true,
  "data": {
    "job_id": "0190a1c0-3333-7000-8000-000000000103",
    "status": "completed",
    "error": null,
    "results": {
      "status": "success",
      "search_type": "1:n",
      "candidate_dataset_id": "8e7d6c5b-4a39-4281-9706-f5e4d3c2b1a0",
      "matches": [
        {
          "id": "d79efad889c32e5537210f024e073632ec65fb9b5feb8576e91cad7c2bdc0466.mp3",
          "score": 1.0,
          "percentage": 100.0,
          "summary": {
            "full_audio_hungarian_mean": 1.0,
            "vocal_hungarian_mean": 1.0,
            "motif_matches_vocals_count": 4,
            "motif_matches_other_count": 6
          }
        }
      ]
    }
  }
}
```

Each match is described in [What the Results Contain](/enterprise-api/trace/comprehensive-search#what-the-results-contain).

### **Job Status Values**

| `data.status` | Meaning |
| :--- | :--- |
| `pending` | Queued, waiting for a worker |
| `processing` | Running |
| `completed` | Finished. Read `results`, or follow `results_url` if `results_complete` is `false` |
| `failed` | Did not finish. Read `error`. You are not charged |

### **Large Results**

If `data.results_complete` is `false`, fetch the full result from `data.results_url`. See [Full Results](/enterprise-api/trace/job-results).

### **Errors**

**Status 404 Not Found** when the job does not exist or belongs to another account:
```json
{
  "error": "ResourceNotFound",
  "message": "job not found",
  "retryable": false
}
```
